# OP2 Playtest Fichas v0.6.0 — Definitiva

Extensão comunitária não oficial para Owlbear Rodeo dedicada ao Playtest Alpha de Ordem Paranormal RPG 2.

A v0.6.0 consolida a linha Recovery em uma versão de acabamento final: preserva a base estável reconstruída a partir da v0.4.0, mantém a integração criada na v0.5.1 e fecha os ajustes funcionais e visuais encontrados no uso real.

## Destaques

- Alan, Edgar, Eloísa, Kênia e Victor.
- Tela PERSONAGENS para o Mestre e resumo para o jogador atribuído.
- Fichas desktop em composição editorial de três regiões; mobile focado em operação rápida e sem carregar a arte de corpo inteiro.
- PV e PD editáveis por botões, com limites, permissões e sincronização de estado.
- Ímpeto, Avaliação, Foco Mental, Foco Emocional e Prontidão com feedback de UI imediatamente sincronizado.
- Dados D4/D6/D8/D10/D12/D20 baseados nos PNGs originais fornecidos para o projeto.
- Dados de atributos, perícias e mecânicas da ficha usam variantes na cor do perfil: Executor vermelho, Analista azul e Vigilante verde.
- O D6 recebe redução visual de escala para ficar proporcional ao restante da família, sem alterar o PNG-base.
- Rolagens integradas ao OP2 Playtest Chat.
- Símbolo ritualístico original no preloader e no ícone da extensão.

A v0.5.0 rejeitada nunca foi usada como fundação estrutural desta linha.
