# OP2 Playtest Fichas — v0.7.7

Este é um conteúdo não oficial, publicado sob a Licença da Comunidade de Ordem Paranormal.

Extensão gratuita para Owlbear Rodeo com as fichas dos cinco sobreviventes do Playtest Alpha. Reúne atributos, perícias, PV/PD, habilidades, efeitos temporários e rolagens integradas ao OP2 Playtest Chat.

## Instalação

Hospede esta pasta em HTTPS e cadastre a URL de `manifest.json` no Owlbear Rodeo. Fichas e Chat podem ser instalados separadamente, mas foram projetados para trabalhar em conjunto.

## Uso

O Mestre atribui um sobrevivente a cada jogador. A ficha acompanha PV, PD, Ímpeto, Avaliação, Prontidão e efeitos preparados. A DT definida pelo Mestre no Chat é reconhecida pelas rolagens da Ficha.

## Compatibilidade e privacidade

- Desenvolvido para Owlbear Rodeo com SDK 3.1.0.
- O estado compartilhado permanece nos metadados da sala do Owlbear.
